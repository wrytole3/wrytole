KAGUMYA MEDDY PROFILE PAGE
============================

Files:
- about.html  -> the finished profile page
- kagumya-meddy.jpg -> your profile photo (you upload this yourself)

HOW TO USE
1. Put about.html in your Wrytole GitHub Pages folder/repository.
2. Upload your professional photo to the same folder.
3. Name the photo exactly: kagumya-meddy.jpg
4. Replace YOUR-EMAIL@example.com with your real email.
5. Replace the LinkedIn, GitHub and Instagram placeholder URLs with your real profiles.
6. If your page URL is different from:
   https://wrytole3.github.io/wrytole/about.html
   update the canonical, og:url and JSON-LD url values in about.html.
7. Link to about.html from your site's main navigation/footer.

SEO NOTE
This page includes a descriptive title, meta description, canonical URL,
Open Graph tags and Schema.org Person structured data. Google may take time
to crawl and index the page; these tags improve clarity but cannot guarantee
a particular Google ranking.
